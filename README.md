# Byte Shop — Dark Theme Release

Open `index.html` in a modern browser. Keep the `assets` folder beside it; the folder contains the five motherboard product images, the Byte Shop logo and supplied motherboard/circuit-board imagery used across the storefront.

This is a static frontend. The catalogue, performance dashboard, product detail views, portfolio, and feedback pages run in the browser. The sample report displays ₹5,00,000 total revenue and ₹7,00,000 total profit. These figures are illustrative website data, not connected to a payment processor or accounting system.

The motherboard product cards currently remain marked out of stock, preserving the template's original availability behavior. Feedback submission only shows a local confirmation; connect a real submission destination before collecting customer feedback publicly. The Feedback page includes illustrative review cards for layout demonstration; replace them with approved, genuine customer reviews before representing them as actual endorsements.


The interface uses a dark black/navy palette with electric-blue and cyan accents, matching the supplied Byte Shop logo. The website directory in this archive is named `Byte Shop`.
